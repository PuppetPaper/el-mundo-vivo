# El Mundo Vivo

Web conceptual de un MMORPG de fantasía persistente, hecha con HTML, CSS y JavaScript sin dependencias de ejecución.

## La experiencia

- Portada de fantasía con tres tratamientos de luz (Amanecer, Ocaso y Noche).
- Llegada en caravana: trabajo, taberna o exploración, con escenas escritas distintas.
- Cinco regiones y siete caminos de vida.
- Los siete días del acontecimiento de Dorskar, resumidos desde la biblia original.
- Tres respuestas alternativas al derrumbe y un encargo cotidiano con tres soluciones.
- Manifiesto, privacidad, procedencia del arte y estado conceptual explícito.

Las interacciones son ramas narrativas preescritas. No hay un juego, una IA activa, cuentas, analítica, cookies propias ni almacenamiento local. Las escenas nuevas se distinguen del resumen de la biblia.

## Arte y tipografías

Las imágenes de `assets/fantasy/` proceden del ejemplo Aethria aportado por el autor para este mismo universo. La fuente declara arte generado con IA; no son capturas de gameplay. Procedencia y hashes: `assets/fantasy/sources.json`. No se afirma licencia de dominio público ni autoría de NEXUS.

Cormorant Garamond y Karla se sirven localmente, con licencia y avisos en `assets/fonts/OFL.txt`.

## Desarrollo y publicación

Desde esta carpeta: `python -m http.server 8765 --bind 127.0.0.1`.

GitHub Pages publica la raíz de `main`: https://puppetpaper.github.io/el-mundo-vivo/ . Las versiones anteriores y su comparativa se han retirado del árbol del sitio por petición del autor; el historial de Git sigue disponible.

El documento privado original no se distribuye. `DESIGN.md` recoge las decisiones y el estado de verificación.
