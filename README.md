# El Mundo Vivo

Web conceptual de un MMORPG de fantasía persistente. HTML, CSS y JavaScript sin dependencias.

Publicación: GitHub Pages desde main, carpeta raíz.

## Desarrollo local

`python -m http.server 8765`

## Contenido

Cinco regiones, siete caminos de vida, crónica interactiva de siete días, manifiesto y privacidad. Ilustraciones SVG originales; no representan gameplay. El documento fuente completo no se incluye.

Sin analítica, cookies propias, formularios ni servicios de pago.
