INFORMACIÓN DEL SITIO

Privacidad y transparencia.

Una web sin seguimiento propio

Esta web no incorpora analítica, publicidad, formularios, cuentas, cookies propias ni almacenamiento local. Las interacciones se ejecutan en tu navegador y no envían tus elecciones a ningún servidor.

Alojamiento

El sitio se aloja en GitHub Pages. GitHub puede registrar información técnica, incluida la dirección IP, para operar y proteger su servicio. Consulta su declaración de privacidad.

Recursos visuales

Las ilustraciones vectoriales son composiciones originales creadas para esta web. Representan una interpretación conceptual del universo; no son capturas de un videojuego. Los recursos se sirven desde el propio sitio, sin fuentes ni imágenes de terceros.

Estado del proyecto

El Mundo Vivo es una propuesta conceptual independiente. No hay un videojuego jugable, una fecha de lanzamiento anunciada ni una campaña de financiación en esta página.
