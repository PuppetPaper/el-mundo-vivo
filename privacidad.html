INFORMACIÓN DEL SITIO

Privacidad y transparencia.

Una web sin seguimiento propio

Esta web no incorpora analítica, publicidad, formularios, cuentas, cookies propias ni almacenamiento local. Las interacciones —la luz de la portada, la llegada, las regiones, los oficios, la crónica, la decisión y el encargo— se ejecutan en tu navegador y no envían tus elecciones a ningún servidor.

Alojamiento

El sitio se aloja en GitHub Pages. GitHub puede registrar información técnica, incluida la dirección IP, para operar y proteger su servicio. Consulta su declaración de privacidad.

Las imágenes

Las ilustraciones de esta web proceden del ejemplo visual Aethria aportado por el autor para este mismo universo. La página de origen declara que fueron generadas con IA. Se reutilizan aquí como arte atmosférico del proyecto, no como capturas de un videojuego ni como prueba de gameplay. No se atribuye dominio público ni autoría de NEXUS sobre ellas; tampoco se afirma que sean canon cerrado. El manifiesto de procedencia, con URL de origen y hashes SHA-256 de cada archivo, está en assets/fantasy/sources.json.

Los once WebP se sirven desde este mismo sitio: hero, las cinco regiones (valdoria, dorskar, namaris, thaloria, eryndor) y cinco escenas (forge, home, forest, guild, adventure). No se cargan imágenes, fuentes ni scripts de terceros en tiempo de ejecución.

Tipografía

Las familias Cormorant Garamond (Copyright 2015 The Cormorant Project Authors) y Karla (Copyright 2019 The Karla Project Authors) se sirven localmente desde este sitio, bajo SIL Open Font License 1.1. No se realizan peticiones a servidores de fuentes de terceros. El texto completo de la licencia y los avisos de copyright están en assets/fonts/OFL.txt.

Escenas y personajes

Las fichas de región, la llegada a Valdoria, la crónica de siete días, sus tres ramas y el encargo del molino son escenas ilustrativas escritas para esta web. No reproducen pasajes literales de la biblia conceptual ni constituyen canon cerrado. Los nombres Adrian, Elias y Lucian aparecen como ejemplos de jugadores de la biblia, no como NPC maestros del mundo.

Estado del proyecto

El Mundo Vivo es una propuesta conceptual independiente. No hay un videojuego jugable, una beta, una fecha de lanzamiento anunciada ni una campaña de financiación en esta página.
